**Beezi is a standalone orchestration platform designed to manage the entire AI-powered development lifecycle.**

This extension serves as the critical bridge for the **"Continue in IDE"** workflow. It allows developers to seamlessly work locally with the code, branches, and implementation plans generated by the Beezi platform.

## Key Features
* **Seamless IDE Hand-off**: Pull AI-generated branches and implementation plans from the Beezi hub directly into your local editor (VS Code or Cursor) for final refinement.
* **Enterprise-Grade Security**: Built with a strict **Zero Data Retention (ZDR)** policy.
* **Full Transparency**: Maintain visibility into every step of the AI orchestration flow directly from your development environment.

## How to Get Started
1. Ensure you have an active account at [beezi.ai](https://beezi.ai).
2. Install this extension.
3. Use the **"Continue in IDE"** button on the Beezi app in your communication tool to pull your orchestrated tasks into VS Code.
